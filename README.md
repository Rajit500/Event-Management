# 🎉 Event Management System

A responsive web-based Event Management System designed to simplify event discovery, registration, and management for students and administrators.

## 📌 About the Project

The Event Management System provides a platform where students can explore events, register for activities, and view important announcements. Administrators can manage events and share updates through a dedicated interface.

This project was developed to practise frontend development, JavaScript, and Firebase integration.

## ✨ Features

- **Student Portal:** Dedicated interface for students.
- **Admin Portal:** Separate interface for administrators.
- **Event Management:** Create, edit, and delete events.
- **Event Registration:** Allows students to register for events.
- **Event Details:** Displays information about available events.
- **Announcements:** Provides a section for important updates.
- **Responsive Design:** Designed to provide a user-friendly interface across screen sizes.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Firebase

## 🚀 Getting Started

### Prerequisites

- A modern web browser.
- A code editor such as Visual Studio Code.
- A local development server, if required by the application.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Rajit500/Event-Management.git
   ```

2. Open the project folder:

   ```bash
   cd Event-Management
   ```

3. Open the project in Visual Studio Code.

4. Run the application using a local development server, such as the Live Server extension.

5. Open the application's main page in your browser.

**Note:** If the project uses Firebase Authentication or database services, configure the required Firebase project settings before running the relevant features.
